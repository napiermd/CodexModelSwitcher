# Connections panel

## Direction contract

THESIS: Show which providers can serve a task and what the bridge is doing at a glance. Move maintenance and account management out of the everyday connection view.

OWN-WORLD: Native macOS system typography, graphite and adaptive system surfaces, cool blue selection, a navy/platinum aperture monogram. Flat model rows, compact provider tabs, visible state text with a symbol. No invented quota graphics.

STORY: Open Harbor, see Baseten's connection and actual request activity, inspect models, or add OpenRouter. Choose task models inside Codex. Settings controls appearance, visible providers, menu bar content, and maintenance.

FIRST VIEWPORT: A 410-point panel with a compact toolbar, four provider tabs, one provider's connection and recent activity, its full model list, and actions. Content determines height up to the current screen's available height. Overflow scrolls only when the screen cannot fit the content.

FORM: Native provider inspector specified by Andrew's CodexBar reference, with a separate Settings view. No concept lottery because the user has supplied the intended structure and requirements. Image generation supplies the replacement icon and a visual direction study; live states and accurate labels override illustrative mock data.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
