One open app.
Room for more models.

Harbor runs in the Dock and menu bar, or just the menu bar. It manages connections and gives each model a stable route into Codex. Codex remembers which route belongs to each task.

Change a model in an existing Harbor task and continue the conversation. An in-progress turn finishes with its original model. Your new-task default affects future tasks.

Reopen Codex once to load the catalog. After that, switch among loaded Harbor models without restarting. Saved-account switching still requires a restart.

Common questions.

Do I need a new task for every model?

No. In a task using the Harbor provider, you can choose another loaded model and continue the same conversation. Older tasks created with the native OpenAI provider need a one-time repair before choosing Harbor models. The repair preserves the conversation and waits for Codex to release the task. Archive and restore can release an inactive task while Codex stays open; an offline repair is also available.

Will my other tasks switch too?

No. Each task stores its own model choice. Harbor's new-task default only affects future tasks. Account sign-ins remain shared connections; separate OAuth identities per task are not supported.

Does this replace my provider subscription?

No. Bring your own account access. Codex uses the account signed in to Codex; Grok uses official CLI OAuth where available; Baseten uses its own API credential. Model Harbor does not sell or include inference.

Can I see usage, spend, and resets?

Yes. The usage view shows Codex and Grok quotas, Baseten organization costs, and OpenRouter key spend. You can put remaining quota, today's spend, or the next reset in the menu bar. Optional CodexBar history adds labeled token-value estimates. See usage sources and coverage.

Can Harbor stay in the Dock and start at login?

Yes. General settings includes Dock and menu-bar presence, remembered close choices, launch at login, and System/Light/Dark appearance. Closing the window keeps the bridge running. Quitting stops it. See lifecycle and startup.

What does warm-up do?

Optional warm-up sends one short, low-effort request through the current Codex account. It is off by default and consumes subscription quota. Choose manual, after-startup, or daily operation. Automatic attempts are limited to once per day while Harbor is idle. Warm-up does not raise rate limits or guarantee faster responses.

Can I add my own provider?

Use Add provider to connect OpenRouter and choose models from its tool-capable catalog. The custom editor supports compatible direct Responses providers. Adding another provider to live Harbor routing requires a code change and compatibility tests. Follow the customization guide.

Is this an official Codex app?

Model Harbor is an independent community project by Andrew Napier. It builds on Hieu Nguyen's CodexModelSwitcher and preserves its MIT license and attribution. It is not endorsed by OpenAI, xAI, Baseten, or 1Password.
