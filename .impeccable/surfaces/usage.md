# Usage and spend

## Direction contract

THESIS: Show account limits, resets, and API costs with their scope and source visible alongside each number.

OWN-WORLD: Extend the existing native macOS provider inspector: system type, cool blue selection, flat rows, restrained separators, and content-fitting height. Preserve the Harbor brand.

STORY: Open Usage & spend, select a provider and account, check remaining quota or costs, then inspect daily history or open the provider dashboard. Account selection only changes the view.

FIRST VIEWPORT: A 410-point panel with compact provider selection, account identity, quota bars or a two-column spend summary, and a daily chart where real history exists. Source, freshness, and refresh controls stay legible. No invented zeroes or fabricated history.

FORM: Andrew's CodexBar reference determines the inspector structure. Account quotas, organization API billing, and local token-value estimates occupy explicitly named views. Background reads reuse credentials without opening a vault.

FINISH: Build and behavior tests, native visual inspection, and the Impeccable finish review verify the shipped surface. Document sources and limitations.
